# scry_document

The `document` kind for [Scry](https://github.com/joetjen/scry)
(lang_spec.md §8.3).

Source: <https://github.com/joetjen/scry_document>. Specs live in the
separate [`scry`](https://github.com/joetjen/scry) repository.
Implementation has not started yet on this branch.

## Installation

```elixir
def deps do
  [
    {:scry_document, "~> 0.1"}
  ]
end
```
